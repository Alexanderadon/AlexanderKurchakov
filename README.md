# Портфолио — Александр Курчаков

Личный сайт-портфолио: frontend-разработчик и дизайнер из Алматы. Сайты, игры, айдентика и видео.

**Живой сайт:** https://portfolio-nu-ochre-2f9g25e8gc.vercel.app

Тёмное bento-портфолио: живой маскот-компаньон, играющие видео-reels прямо в карточках,
два режима работ (сетка / кинетический список), переключатель палитр и шрифтов.
При первом заходе — готический прелоадер: глаз, собор и курсор-факел.

## Стек

- **Vite 8** + **React 19** + **TypeScript** (strict)
- **React Router 8** (framework mode, `ssr:false` + prerender главной в статику)
- **Tailwind v4** подключён (плагин `@tailwindcss/vite`); базовый дизайн — на портированной
  дизайн-системе в `app/app.css` (токены палитр/шрифтов через `data-*` на `<html>`)
- **WebGL** и **Canvas 2D** без библиотек: туман, руки, чернильный след, прелоадер
- **Vitest** (jsdom) + **Playwright** (Chromium, Firefox, WebKit, iPhone)
- Шрифты локально (Unbounded, Onest, Cinzel, Old Standard TT) — `public/fonts/`
- Медиа файлами в `public/` (видео `.mp4`, картинки, персонажи `.svg`, `resume.pdf`)

## Разработка

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # прод-сборка: build/client (+ статический index.html из prerender)
npm run typecheck  # react-router typegen && tsc
npm test           # модульные тесты
npm run e2e        # сквозные, поднимает боевую сборку
npm run check      # всё вместе
```

> Требуется Node ≥ 22.22 (проект собирается и на 22.20 с предупреждением).

Для сквозных тестов нужны движки: `npx playwright install chromium firefox webkit`.

## Структура

```
app/
  root.tsx                 # <html lang=ru>, предзагрузка шрифтов, инлайн boot-скрипт
  lib/boot.ts              # то, что обязано отработать ДО первой отрисовки:
                           #   палитра из localStorage и решение о показе прелоадера
  routes/home.tsx          # единственный маршрут: провайдеры + секции
  components/              # Hero, Works, About, Hands, Fog, Mascot, InkTrail…
  components/preloader/    # прелоадер: шейдер сцены, глаз, прогресс, раскладка слов
  app.css                  # дизайн-система: токены, палитры, компоненты
e2e/                       # сквозные тесты (Playwright)
public/                    # fonts, video, img, characters, photo, resume.pdf
_handoff/                  # исходный макет-референс bento-v2 (в сборке не участвует)
```

### Прелоадер

Показывается один раз за сессию, пропускается при `prefers-reduced-motion` и включённой
экономии трафика. Прогресс тянется за реальной загрузкой (шрифты, текстуры, постер героя),
а не за таймером: пол 1.1 с, чтобы не мигнул, потолок 4.2 с и жёсткий предел 6.5 с, чтобы
зависший ассет не подвесил сайт. Посмотреть повторно — `?preload` в адресе.

Фон — один фрагментный шейдер. Собор и бумага перекрашиваются попиксельно, а не через
`ctx.filter`: в Safari он поддержан частично, и цепочка фильтров молча отбрасывается.

## Тесты

Модульные покрывают чистую логику: прогресс, геометрию, раскладку слов, перекраску,
boot-скрипт. Рисование на canvas и WebGL из покрытия исключено намеренно — в jsdom его
строки исполнились бы на заглушках и ничего бы не доказали.

Сквозные гоняются на **боевой сборке** в четырёх целях. Три движка не для галочки: баг,
при котором вместо собора появлялся светлый прямоугольник в пол-экрана, воспроизводился
только в WebKit.
