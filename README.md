# Портфолио — Александр Курчаков

Личный сайт-портфолио: frontend-разработчик и дизайнер из Алматы. Сайты, игры, айдентика и видео.

Тёмное bento-портфолио: живой маскот-компаньон, играющие видео-reels прямо в карточках,
два режима работ (сетка / кинетический список), переключатель палитр и шрифтов.

## Стек

- **Vite 8** + **React 19** + **TypeScript**
- **React Router 7/8** (framework mode, SSR + prerender главной в статику)
- **Tailwind v4** подключён (плагин `@tailwindcss/vite`); базовый дизайн — на портированной
  дизайн-системе в `app/app.css` (токены палитр/шрифтов через `data-*` на `<html>`)
- Шрифты локально (Unbounded 800 + Onest 400, woff2, cyrillic+latin) — `public/fonts/`
- Медиа файлами в `public/` (видео `.mp4`, картинки, персонажи `.svg`, `resume.pdf`)

## Разработка

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # прод-сборка: build/client (+ статический index.html из prerender)
npm run typecheck  # react-router typegen && tsc
```

> Требуется Node ≥ 22.22 (проект собирается и на 22.20 с предупреждением).

## Структура

```
app/
  root.tsx          # <html lang=ru>, локальные шрифты, boot-скрипт (палитра из localStorage)
  routes/home.tsx   # единственный маршрут: инъекция разметки + запуск initSite()
  site-markup.ts    # разметка страницы (портирована 1:1 из утверждённого макета)
  site-script.ts    # вся интерактивность (маскот, фильтры, видео, курсор, reveal)
  app.css           # дизайн-система: токены, палитры, компоненты
public/             # fonts, video, img, characters, photo, resume.pdf
_handoff/           # исходный макет-референс bento-v2 + сырые ассеты (не участвует в сборке)
```

Разметка и стили портированы из утверждённого макета. Чтобы добавить работу — отредактируйте
соответствующую карточку `.work` (и парную строку `.irow`) в `app/site-markup.ts` и положите
медиа в `public/`.

## Деплой

Сайт после сборки — статический (`build/client/index.html` + ассеты), деплоится на любой
статический хостинг. Для Vercel: подключить репозиторий, framework preset «React Router»,
либо отдавать `build/client` как static output. Домен подключается в настройках Vercel.
